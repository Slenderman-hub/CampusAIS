# АИС «Учебный кампус: Расписание и аудитории»

Репозиторий содержит практическую реализацию модульной архитектуры системы, предназначенной для просмотра расписания и бронирования аудиторий.

## Архитектура
Система разделена на клиентское приложение и интеграционный шлюз, общающиеся через REST API.
* **Клиент:** WPF (.NET 8.0) — предварительная валидация и UI.
* **Шлюз:** ASP.NET Core Web API (.NET 8.0) — авторитетная проверка конфликтов и интеграция.
* **Контракты:** Общие DTO, вынесенные в отдельный проект без обратных зависимостей.

## Структура решения
* `src/` — исходный код (Shared, Client, Gateway)
* `tests/` — unit-тесты для клиента и шлюза
* `docs/` — проектная документация (диаграммы и спецификация API)
